# 🧪 Расчет потребления NaOH в скрубберах термодеструкционных установок

Профессиональное интерактивное приложение на **Streamlit** для выполнения технологических и материальных расчетов системы мокрой газоочистки (скрубберов) термических установок по обезвреживанию отходов.

---

## 📌 Раздельная структура расчетов

Приложение выполняет независимые расчеты материального баланса и расхода нейтрализующего реагента ($\text{NaOH}$) для **двух отдельных установок**, а также формирует сводную ведомость:

1. **💧 Установка №1: Утилизация жидких отходов (КТОЖС)**
   - Часовой расход: **$1{,}5\text{ м}^3/\text{ч}$** ($1500\text{ кг/ч}$);
   - Два нормативных набора концентраций по **СП 320.1325800.2017 (Таблица Г.1)**:
     * **Набор 1: «Молодой полигон» (кислая фаза)**: $\text{Cl}^- = 5000\text{ мг/дм}^3$, $\text{SO}_4^{2-} = 1500\text{ мг/дм}^3$;
     * **Набор 2: «Старый полигон» (метаногенная фаза)**: $\text{Cl}^- = 2500\text{ мг/дм}^3$, $\text{SO}_4^{2-} = 400\text{ мг/дм}^3$;
     * Возможность ввода произвольных концентраций.
   - Независимый расчет расхода $\text{NaOH}$ и емкости склада для жидких отходов.

2. **🗑️ Установка №2: Утилизация ТБО и промышленных отходов**
   - Производительность: **$170\text{ кг/ч}$** (калорийность $2500\text{ ккал/кг}$);
   - Задание содержания активных кислотообразующих гетероатомов ($\text{Cl}, \text{S}$):
     * Прямой ввод средневзвешенного содержания $\text{Cl}\%$ и $\text{S}\%$ в смеси;
     * По морфологическим группам отходов с интерактивными пресетами (РТИ, полимеры, нефтепродукты, антифризы, ветошь, фильтры и др.).
   - Независимый расчет расхода $\text{NaOH}$ и емкости склада для ТБО.

3. **📊 Сводная ведомость и Сравнение**
   - Сводный баланс при одновременной работе обеих установок;
   - Сопоставление нагрузок и расходов реагента.

---

## ⏱️ Учет сменности, простоев и удельных норм

- **Длительность смены в сутки ($T_{\text{сут}}$)**: по умолчанию **$24\text{ ч/сут}$** ($8\text{ ч}$, $12\text{ ч}$, $16\text{ ч}$, $24\text{ ч}$);
- **Количество рабочих дней в году ($D_{\text{год}}$)**: по умолчанию **$365\text{ дн/год}$** (с корректировкой на ППР и ремонт);
- **Годовой фонд рабочего времени**: $T_{\text{год}} = T_{\text{сут}} \times D_{\text{год}}$ часов в год;
- **Удельный расход на 1 кг отхода**:
  * г $100\%$ чистого $\text{NaOH}$ / кг отхода;
  * г рабочего раствора / кг отхода;
  * кг $\text{NaOH}$ / м³ стоков (для жидких отходов).

---

## 📐 Расчетные формулы в отчетах

1. **Образование кислых газов**:
   - $M_{\text{HCl}} = M_{\text{Cl}} \times k_{\text{конв, Cl}} \times \frac{36{,}461}{35{,}453} = M_{\text{Cl}} \times 0{,}98 \times 1{,}0284$ (кг/ч)
   - $M_{\text{SO}_2} = M_{\text{S}} \times k_{\text{конв, S}} \times \frac{64{,}063}{32{,}065} = M_{\text{S}} \times 0{,}90 \times 1{,}9979$ (кг/ч)
2. **Стехиометрическая нейтрализация**:
   - $\text{HCl} + \text{NaOH} \rightarrow \text{NaCl} + \text{H}_2\text{O}$ ($k = 1{,}0970$ кг $\text{NaOH}$ / кг $\text{HCl}$)
   - $\text{SO}_2 + 2\text{NaOH} \rightarrow \text{Na}_2\text{SO}_3 + \text{H}_2\text{O}$ ($k = 1{,}2487$ кг $\text{NaOH}$ / кг $\text{SO}_2$)
3. **Фактический часовой, суточный и годовой расход**:
   - $M_{\text{NaOH, факт}}^{\text{час}} = M_{\text{NaOH}}^{\text{теор}} \times \frac{k_{\text{изб}}}{\eta_{\text{скр}}}$ (кг/ч)
   - $M_{\text{NaOH, факт}}^{\text{сут}} = M_{\text{NaOH, факт}}^{\text{час}} \times T_{\text{сут}}$ (кг/сут)
   - $M_{\text{NaOH, факт}}^{\text{год}} = \frac{M_{\text{NaOH, факт}}^{\text{час}} \times T_{\text{год}}}{1000}$ (т/год)
